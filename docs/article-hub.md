# 半导体行业文章库

## 目标

为研究团队集中维护高质量半导体公众号文章，支持按公众号、关键词和阅读状态回看历史内容，并保留微信原文入口。

## 首版范围

- 默认公众号：半导体行业观察、芯智讯。
- 支持导入公开的 `mp.weixin.qq.com/s/` 文章链接。
- 提取标题、公众号、发布时间、摘要和正文。
- 按公众号、关键词、未读状态筛选，支持发布时间和导入时间排序。
- 站内使用受限 iframe 阅读清洗后的正文；复杂交互和视频回到微信原文。
- URL 去重、正文脚本清理、来源域名白名单和阅读状态持久化。

## 手动更新约束

微信公众号没有适用于任意公众号的稳定公开历史文章 API，原文页也通过 CSP 禁止第三方网站直接嵌入。自动发现不应依赖搜索结果页抓取或绕过微信校验。

当前采用按需手动更新，不启用定时任务。研究人员在文章页点击“更新文章”后，系统才要求本地 WeWe RSS 刷新已授权公众号，并执行增量入库：

```text
WeWe RSS（自建，扫码登录直连微信读书）
  -> 用户点击“更新文章”
  -> 刷新并读取 RSS/Atom
  -> 按原文 URL 去重
  -> 获取并清洗正文
  -> 文章库
```

RSS 服务不可用时保留人工链接导入，不阻塞文章浏览。

订阅服务的账号登录、书架查询和公众号文章列表均直接请求
`weread.qq.com`，不再依赖已下线的 `weread.111965.xyz` 公共中转。
微信读书登录 Cookie 仅保存在服务器本机 SQLite，账号列表接口不会返回该字段。

## 下一阶段验收

- 支持全部公众号手动触发同步，未配置公众号不会影响已配置来源。
- 展示上次成功时间、新增数量和失败原因。
- 手动更新失败不会删除或覆盖已有文章。
- 相同原文链接重复同步不会产生重复记录。
- 自动同步仅拉取增量，并保留微信原始链接。
- 至少用两个公众号连续验证 7 天，记录同步成功率和延迟。

## 后续能力

- 将选中文章加入 RAG 临时研究范围，但与正式研报知识库隔离。
- 周报摘要与热点主题聚合。
